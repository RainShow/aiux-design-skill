# 预置导航图标（语义优先）

写顶栏 / 侧导 / `navConfig` 时：**先按菜单中文名查本表**，命中则用预置 SVG；没有再补文件并登记 `scripts/components/navIcons.ts`。

代码入口：`scripts/components/navIcons.ts` 的 `NAV_PRESET_ICONS` / `resolveNavIcon('数据集成')`。

落地：`assets/nav/**` → 项目 `src/assets/nav/`；`navIcons.ts` 内保持 `../../assets/nav`。

## 强制

1. **语义优先**：菜单叫「数据集成」就用键 `数据集成`，不要凭感觉换 `service.svg` 或 Arco `IconApps`。
2. **查不到才新增**：新 SVG 放到对应子目录（见下），并在 `NAV_PRESET_ICONS` 加键（中文名 = 菜单名）。
3. **同名不同产品**：短键给双列全模态；应用开发「工作流」用 `应用工作流`，本体「主页」用 `本体主页`。
4. 壳层控件（折叠 / 全景汉堡 / 顶栏文档铃铛）也走本表，不要另引一套。

## 目录

| 目录 | 用途 |
|------|------|
| `assets/nav/rail/` | 双列一级轨（主页、集成、服务…） |
| `assets/nav/group/` | 双列二级分组 / 叶子入口 |
| `assets/nav/app-dev/` | 应用开发单列 |
| `assets/nav/model-dev/` | 模型开发单列 |
| `assets/nav/ontology/` | 本体构建单列 |
| `assets/nav/platform/` | 平台管理单列 |
| `assets/nav/org-select/` | 位置选择器（组件内已引用，不必进 `navConfig`） |
| `assets/nav/shell/` | 壳层：fold / unfold / putaway / 顶栏文档铃铛 / 箭头 |

## 用法

```ts
import { NAV_PRESET_ICONS, resolveNavIcon } from './navIcons'

const integrateIcon = resolveNavIcon('数据集成') ?? NAV_PRESET_ICONS['数据集成']

// navConfig
{ key: 'integrate', label: '数据集成', iconSrc: NAV_PRESET_ICONS['数据集成'] }
```
